---

同じエージェントを、ターミナルで。アカウント、セッション、設定はアプリと共通です。

## 起動する

| コマンド | 動作 |
|---|---|
| `letronna` | 会話を開く |
| `letronna -p "question"` | 一度だけ質問し、答えを表示して終了 |
| `letronna --continue` | 直近のセッションを再開 |
| `letronna --resume` | 最近のセッションから選ぶ。ID を付けるとそのセッションを開く |
| `letronna gui` | 代わりにウィンドウを開く |
| `letronna setup` | 名前、ログイン、ゲートウェイ、モデル、インストール |
| `letronna --uninstall` | アンインストール |

`--plan` は計画モードで起動します：読み取りと検索だけを行い、書き込みも実行もしません。`--yes` はツールを確認なしで実行します。安全が確かな場面だけで使ってください。

## スラッシュコマンド

会話中に `/` と入力すると、次の一覧が表示されます：

| コマンド | 動作 |
|---|---|
| `/help` | ここで Letronna にできること |
| `/new` | 新しいセッションを開始 |
| `/plan` | 読み取りと検索のみ。書き込みも実行もしない |
| `/model` | モデルの表示や変更。image、speech、video を付けるとそれぞれのモデルを指定 |
| `/gateways` | ゲートウェイの表示、追加、削除 |
| `/team` | ホスト型モデルの支払い先をチームか自分かに切り替え |
| `/login` | Letronna にログイン |
| `/logout` | このマシンでログアウト |
| `/whoami` | ログイン中のユーザー |
| `/effort` | モデルがどれだけ深く考えるか |
| `/thinking` | モデルの思考を表示、または非表示 |
| `/search` | モデルに Web 検索を許可 |
| `/jobs` | バックグラウンドで実行中のコマンド |
| `/skills` | モデルに渡せる保存済みの指示 |
| `/resume` | 以前のセッションを再開 |
| `/where` | プロジェクトフォルダーとセッションファイルを表示 |
| `/clear` | 画面を消去 |
| `/exit` | 終了 |
