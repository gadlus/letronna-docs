title: "はじめに"
description: "アカウントを作り、Letronna をインストールしてログインし、何か聞いてみる。"
---

Letronna は、作業中もそばに開いたままにしておける AI エージェントです。ウィンドウとして使え、ターミナルでも同じエージェントが動きます。ファイルを読み書きし、コマンドを実行し（事前に確認します）、あなたに関するメモをお使いのディスクに保存し、選んだモデルと対話します。

## 1. アカウントを作る

letronna.ai で[アカウントを作成](/signup)します。Letronna がアルファ版の間、ダウンロードにはアカウントが必要です。アカウントには、Letronna が提供するホスト型モデル用のクレジット、プラン、チームも紐づきます。

## 2. インストールする

ダッシュボードの[ダウンロード](/dashboard/download)を開きます。お使いの OS が最初に表示されます：

- **macOS**（13 以降、Apple シリコン）：.dmg を開き、Letronna を「アプリケーション」にドラッグします。
- **Windows**（11、x64）：.zip をダウンロードして解凍し、`letronna.exe setup` を実行します。または、1 行のコマンドをコピーして PowerShell に貼り付ければ、両方が一度に行われます。
- **Linux**（x64、glibc 2.31 以降）：.tar.gz をダウンロードして展開し、`./letronna setup` を実行します。または、1 行のコマンドをターミナルに貼り付けます。

1 行のコマンドに含まれるダウンロードリンクは数分間だけ有効です。それ以降はもう一度コピーしてください。管理者権限は不要で、コンピュータ上のご自身のユーザーアカウントの外には何も置かれません。

## 3. 初期設定をする

`letronna setup` は、呼び名を尋ね、ログインし、ゲートウェイとモデルを選び、ウィンドウ、ターミナル、またはその両方を、指定した場所にインストールします。設定を変えたいときは、いつでも再実行できます。Windows と Linux では、その後アプリがスタートメニューまたはアプリケーションメニューに表示されます。

## 4. ログインする

ログインは letronna.ai 上で行います。アプリが自動でそのページを開くか、ターミナルで `/login` を実行します。ログインすると、そのコンピュータが[デバイス](/dashboard/devices)に表示されます。

## 5. 何か聞いてみる

メッセージを入力します。Letronna は選んだモデルで答え、コマンドの実行やファイルの変更の前には確認します。ホスト型モデルの料金はクレジットから差し引かれます。代わりに自分の API キーを使うには、[ゲートウェイ](/docs/gateways)を参照してください。
