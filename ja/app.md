ウィンドウは、エージェントとのチャットです。左側にセッションが一覧表示され、検索、ピン留め、日付ごとのグループ分けができます。各セッションはディスク上の独立したファイルなので、Letronna を 2 つ同時に起動することもできます。

## エージェントと話す

- 返答は Markdown としてストリーミング表示されます。エージェントが使うツール（ファイルの読み取り、コマンドの実行、Web ページの読み取り、過去のセッションの検索）はチャットに表示され、コンピュータに変更を加える操作は事前に確認します。
- モデルはモデルメニューから選びます。Letronna のモデルと、設定した各ゲートウェイのモデルがすべて並び、メッセージは選んだモデルのゲートウェイに送られます。
- 思考の深さ（effort）、思考の表示（thinking）、Web 検索は、モデルが対応していれば切り替えられます。
- 会話がモデルのコンテキストウィンドウに収まらなくなると、古いやり取りは忘れられるのではなく要約されます。

## 設定

- **Gateways**：各ゲートウェイの状態（ログイン済み、接続済み、未設定、未起動）と、そのキー。
- **Account**：ログインしているユーザー、クレジット、そしてホスト型モデルの支払い元（自分か、所属するチームか）。

ウィンドウには Telegram や Discord からもアクセスでき、スケジュール実行の結果もそこに届きます。Artifacts と Skills には、それぞれ専用のページがあります。

## OS ごとの違い

|  | Windows | Linux | macOS |
|---|---|---|---|
| チャットとエージェントのツール | はい | はい | はい |
| 自動インストールとアンインストール | はい | はい | 「アプリケーション」にドラッグ |
| ウィンドウは同時に 1 つ | はい（開いているウィンドウを前面に） | はい | いいえ |
| トレイアイコン | はい | はい（KDE は対応、GNOME は AppIndicator が必要） | いいえ |
| ダイアログ背後のぼかし | はい | いいえ | いいえ |

Windows と Linux では、ウィンドウを閉じても Letronna はトレイに残ります。アイコンをクリックすると戻り、右クリックで終了します。アンインストールは、Windows では「アプリと機能」から、または `letronna --uninstall` で行います。
