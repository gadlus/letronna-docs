Letronna Cloud は、同じ Letronna のエージェントを、お使いのコンピュータではなく Letronna のサーバー上で動かすものです。送ったタスクは、アプリやノート PC を閉じても進み続け、作ったものは立ち上げたままにできます：Web アプリには専用の URL が付き、サービスは動かし続けられます。[Pro](/dashboard/billing) で利用でき、料金はクレジットから差し引かれます。

## クラウドでタスクを実行する

ウィンドウでもターミナルでも、チャットでエージェントに頼むだけです：「これをクラウドで実行して」と言うか、時間のかかるビルドなど、このコンピュータが苦手なことを頼みます。クレジットを消費するため、Letronna はタスクを送る前に確認します。クラウドからはお使いのコンピュータの中身は見えないので、タスクには必要なものをすべて持たせるか、クローンする https の git リポジトリを指定します。

- 各タスクは専用のコンテナで実行され、サイズに応じたメモリと時間が与えられます：**軽量（light）**はメモリ 512 MB で 15 分、**標準（normal）**は 1 GB で 30 分、**高負荷（heavy）**は 2 GB で 1 時間です。
- 進行状況は実行中に表示され、アプリを閉じても止まりません。止まるのは、停止（Stop）を押したときだけです。
- クラウド上の会話はフォルダーと履歴を保持するので、次のメッセージは前回の続きから進められます。
- 作ったものは、回答内のプレビューリンクから開けます。

ターミナルからは直接送ることもできます：`letronna cloud "task"` に、`--repo <url>`、`--tier light|normal|heavy`、そして続きから進めるための `--thread <id>` を付けます。

## オンラインのままにするサービス

動かし続ける必要があるものを頼みます。たとえば「ショップの在庫を 1 時間ごとにチェックして、少なくなったらメールして。**ずっと動かしておいて**」のように。スケジューラー、Webhook の受信、チャットボットは、どれも同じ仕組みで動きます。Letronna はそれを作ってテストし、**ワーカー**として動かし続けます。「ずっと動かしておいて」（または「オンラインのままにして」）と言うのは、本当にそうしたいときだけにしてください。それ以外は一度実行して止まります。

- ワーカーは止まると再起動されます。10 分間に 5 回クラッシュすると、理由を示して完全に停止します。
- メモリは、より多く必要な場合を除いて 256 MB です（128〜512 MB の範囲）。1 アカウントで動かし続けられるのは 3 つまでです。
- 料金は 1 時間単位でクレジットから差し引かれ、クレジットがなくなると停止します。128 MB のサービスを 1 か月間オンラインにしておくと約 $0.75、256 MB なら約 $1.50 です。
- API トークンなど必要なキーは、コードの中ではなく、そのフォルダー内の `/work/.env` に置きます。

## 専用 URL を持つ Web アプリ

Letronna がクラウドで作った Web アプリは、専用のアドレス `https://lc-<id>.letronna.si` で稼働させたままにできます。最初のアクセスで起動し、アクセスが 10 分間ないと休止します。起動しているのは 1 日最大 8 時間で、料金がかかるのは起動している間だけです。

## 管理する

[Cloud ページ](/dashboard/cloud)には、ホストしているものの一覧が、それぞれの最新の出力、停止・起動・再起動のボタン、これまでの費用とともに表示され、送ったタスクもそれぞれの費用付きで並びます。チャットでエージェントに聞くこともできます（「在庫チェックの調子はどう？」「止めて」）：Letronna は読み取りを確認なしで行い、停止や起動の前には確認します。

## 料金

| 項目 | 料金 |
|---|---|
| コンピューティング（タスク、ワーカー、起動中の Web アプリ） | メモリ 1 GB あたり月約 $6、1 秒単位で課金 |
| タスクが使うモデル | ほかのホスト型リクエストと同じく、[モデルページ](/dashboard/models)の価格 |
| 256 MB のサービスを 1 か月間オンラインにした場合 | 約 $1.50 |

すべての課金は、[使用量ページ](/dashboard/usage)の Cloud の欄に表示されます。

## 禁止事項

マイニング、他のマシンへのフラッド攻撃、そして[利用規約](/terms)が禁じるすべてのこと。不正利用の監視機能がすべてのコンテナを見張っています：マイナーやフラッド攻撃は即座に停止され、それ以外の不審な挙動はチームに報告されます。クラウドに届くのは Web トラフィックだけなので、ゲームサーバーなど他のポートを開くことは今のところできません。

## クラウド上のデータ

会話のフォルダーと、Letronna がその会話のために保持しているものは、使っている間は Letronna のサーバーに残り、14 日間使われないと削除されます。ただし、その中でワーカーが動き続けている場合は削除されません。サポートがタスクとその回答を読めるのは、あなたが許可した場合だけで、閲覧はすべて記録されます。
