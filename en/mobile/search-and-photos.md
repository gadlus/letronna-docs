## Web search

An answer can search the web. While it does, the chat says "Searching the web"; after, the answer keeps a card with the sources it found.

How it searches is set in Settings > **Web search**:

| Choice | Does |
|---|---|
| **Auto** | Letronna's free search first, and the paid one, from your credit, when it finds nothing |
| **Free** | Letronna's free search alone: no credit is used; it can find less |
| **Paid** | the paid search alone, from your credit, for each search |

## Photos

Tap **Add photos** in the composer, then **Choose photos** or **Take a photo**.

Not every model reads photos. If the model reads text only, the composer says so: pick a model with the picture mark in the [model menu](/docs/mobile/models), or use the **Reads images** filter there. For models on the iPhone, see [Working offline](/docs/mobile/offline).

A photo goes only with the message it came in.

Photos cannot go to your computer or to a code session yet. There, the words are sent alone.
