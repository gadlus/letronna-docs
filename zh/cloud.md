Letronna Cloud 是同一个 Letronna 智能体，只是运行在 Letronna 的服务器上，而不是你的电脑上。发送到那里的任务在你关掉应用或合上电脑后仍会继续，它构建的东西也可以一直在线：网页应用会获得专属链接，服务可以持续运行。[Pro](/dashboard/billing) 套餐可使用，费用从你的额度中扣除。

## 在云端运行任务

只需在聊天中（窗口或终端都可以）对智能体说：“在云端运行这个”，或者任何这台电脑做不好的事，比如一次耗时很长的构建。因为会消耗额度，Letronna 在发送任务前会先询问你。云端看不到你电脑上的任何东西，所以任务会带上它需要的一切，或者带上一个可供克隆的 https git 仓库。

- 每个任务都在自己的容器中运行，内存和时长取决于规格：**轻量** 512 MB、15 分钟；**标准** 1 GB、30 分钟；**重型** 2 GB、一小时。
- 进度会实时显示，关闭应用不会停止任务；只有 Stop 才会。
- 云端的对话会保留自己的文件夹和历史，所以下一条消息会接着上一条继续。
- 它生成的内容可以通过回答中的预览链接打开。

在终端中也可以直接发送一个任务：`letronna cloud "task"`，可加上 `--repo <url>`、`--tier light|normal|heavy`，以及用 `--thread <id>` 接着之前的对话继续。

## 保持在线的服务

提出一个需要持续运行的需求，比如：“每小时检查一次我店铺的库存，有商品快卖完时给我发邮件，并**保持运行**”。定时作业、Webhook 接收端或聊天机器人都是同样的做法。Letronna 会先构建并测试，然后把它作为**工作进程**（worker）留在云端运行。只有在你确实需要时才说“保持运行”（或“保持在线”）：否则任务只运行一次就停止。

- 工作进程停止后会自动重启；如果十分钟内崩溃五次，就会被永久停止，并说明原因。
- 它默认获得 256 MB 内存，需要时可以更多（128 到 512 MB）；每个账户最多可以同时运行三个。
- 它按小时计费，从你的额度中扣除；额度用完就会被停止。一个 128 MB 的服务全月在线约需 $0.75，256 MB 的约需 $1.50。
- 它需要的密钥（比如 API 令牌）放在其文件夹中的 `/work/.env` 里，而不是写在代码里。

## 带专属链接的网页应用

Letronna 在云端构建的网页应用可以在自己的专属网址上一直在线：`https://lc-<id>.letronna.si`。它在第一次访问时唤醒，十分钟无人访问后休眠，每天最多唤醒八小时。你只需为它唤醒的时间付费。

## 管理它们

[Cloud 页面](/dashboard/cloud)列出你托管的项目，包括各自最近的输出、停止、启动和重启按钮、各自的花费，以及你发送的任务及其花费。也可以在聊天中询问（“我的库存监控怎么样了？”“停掉它”）：Letronna 读取它们时不会询问，但在停止或启动之前会先问你。

## 费用

| 项目 | 价格 |
|---|---|
| 计算资源（任务、工作进程、唤醒中的网页应用） | 每 GB 内存每月约 $6，按秒计费 |
| 任务使用的模型 | 与其他托管请求相同，见[模型页面](/dashboard/models) |
| 一个 256 MB 的服务全月在线 | 约 $1.50 |

每一笔费用都列在[用量页面](/dashboard/usage)的 Cloud 项下。

## 不允许的事

挖矿、向其他机器发起洪水攻击，以及[服务条款](/terms)禁止的任何事。滥用防护会监视每个容器：挖矿程序或洪水攻击会被立即停止，其他看起来不对劲的情况会通知 Letronna 团队。只有网页流量能到达云端，所以游戏服务器和其他开放端口目前还不可行。

## 你在云端的数据

对话的文件夹以及 Letronna 为它保存的内容，在你使用期间保留在 Letronna 的服务器上；连续 14 天未使用后会被删除，除非其中还有工作进程在运行。只有在你允许的情况下，客服才能查看任务及其回答，而且每次查看都会被记录。
