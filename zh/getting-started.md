Letronna 是一个始终在你身边待命的 AI 智能体：一个窗口，以及终端里的同一个智能体。它会读写文件、运行命令（先征求你的同意）、在你的磁盘上记录关于你的笔记，并与你选择的任何模型对话。

## 1. 创建账户

在 letronna.ai 上[注册](/signup)。Letronna 处于 Alpha 阶段期间，下载需要账户；账户还承载你用于托管模型的额度、你的套餐和你的团队。

## 2. 安装

在控制台中打开[下载](/dashboard/download)页面。它会优先显示你自己的系统：

- **macOS**（13 及以上，Apple 芯片）：打开 .dmg，把 Letronna 拖到“应用程序”文件夹。
- **Windows**（11，x64）：下载 .zip，解压后运行 `letronna.exe setup`；或者复制那条单行命令并粘贴到 PowerShell 中，一步完成下载和安装。
- **Linux**（x64，glibc 2.31 及以上）：下载 .tar.gz，解压后运行 `./letronna setup`；或者把单行命令粘贴到终端中。

单行命令里带有一个下载链接，只在几分钟内有效；过期后请重新复制。整个过程不需要管理员权限，也不会写入这台电脑上你自己账户之外的任何地方。

## 3. 设置

`letronna setup` 会问你希望怎么称呼你、让你登录、选择网关和模型，并把窗口、终端或两者安装到你选择的位置。随时可以再次运行它来更改这些选择。在 Windows 和 Linux 上，应用随后会出现在开始菜单或应用程序菜单中。

## 4. 登录

登录在 letronna.ai 上完成：应用会为你打开它，或者在终端中运行 `/login`。之后这台电脑会显示在[设备](/dashboard/devices)中。

## 5. 问它点什么

输入一条消息。Letronna 会用你选择的模型回答，并在运行命令或更改文件之前先询问你。使用 Letronna 托管的模型会从你的额度中扣费；如果想改用你自己的 API 密钥，请参阅[网关](/docs/gateways)。
