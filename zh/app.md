窗口就是一个与智能体对话的聊天界面。会话列在左侧，支持搜索、置顶和按日期分组；每个会话都是你磁盘上的一个独立文件，因此可以同时运行两个 Letronna。

## 与它对话

- 回复以 Markdown 形式流式显示。智能体使用的工具（读取文件、运行命令、读取网页、搜索过去的会话）都会显示在聊天中，任何会改变你电脑的操作都会先询问你。
- 从模型菜单中选择模型。菜单列出 Letronna 以及你设置的每个网关的所有模型，消息会发送到你所选模型的网关。
- 在模型支持的情况下，可以切换推理强度（effort）、思考和网页搜索。
- 当对话超出模型的上下文窗口时，较早的轮次会被总结，而不是被遗忘。

## 设置

- **Gateways**（网关）：每个网关的状态（已登录、已连接、未设置、未运行）及其密钥。
- **Account**（账户）：当前登录的是谁、你的额度，以及由谁支付托管模型的费用：你自己，还是你所在的团队。

也可以通过 Telegram 和 Discord 访问窗口，定时作业也会在那里汇报。Artifacts 和 Skills 各有自己的页面。

## 各系统上的差异

|  | Windows | Linux | macOS |
|---|---|---|---|
| 聊天和智能体工具 | 是 | 是 | 是 |
| 自行安装与卸载 | 是 | 是 | 拖到“应用程序”文件夹 |
| 同一时间只开一个窗口 | 是，并聚焦已打开的窗口 | 是 | 否 |
| 托盘图标 | 是 | 是（KDE；GNOME 需要 AppIndicator） | 否 |
| 对话框背后的模糊效果 | 是 | 否 | 否 |

在 Windows 和 Linux 上，关闭窗口后 Letronna 会留在托盘中：点击图标可以把窗口找回来，右键点击可以退出。在 Windows 上可从“应用和功能”卸载，或者运行 `letronna --uninstall`。
