# Contributing

Thank you for helping. Small fixes are as welcome as new guides.

## Fix a page

1. Open the page on letronna.ai/docs and click **Edit this page on GitHub**, or find its file under `en/`.
2. Make the change and open a pull request.

## Add a page

1. Add a Markdown file under `en/`, with a `title` and `description` at the top.
2. Add its path, without `.md`, to `sidebar.json` in the group it belongs to. To put it under another page, use `{ "page": "...", "pages": [...] }`.
3. Open a pull request.

## Translate a page

Copy the English file into the language's folder with the same name and translate it. Keep the code, commands and links as they are.

## How to write

- Plain words and short sentences.
- Say what the reader does, in the order they do it.
- Every command goes in a code block.
- Write about what Letronna does today, not plans.

Every pull request is read before it is merged.
