같은 에이전트가 터미널에서, 앱과 같은 계정, 세션, 설정으로 실행됩니다.

## 실행하기

| 명령 | 하는 일 |
|---|---|
| `letronna` | 대화 열기 |
| `letronna -p "question"` | 한 번 묻고 답을 출력한 뒤 종료 |
| `letronna --continue` | 가장 최근 세션 이어 가기 |
| `letronna --resume` | 최근 세션 중에서 고르기, id를 주면 그 세션 열기 |
| `letronna gui` | 대신 창 열기 |
| `letronna setup` | 이름, 로그인, 게이트웨이, 모델, 설치 |
| `letronna --uninstall` | 다시 제거하기 |

`--plan`은 Plan 모드로 시작합니다: 읽기와 검색만 하고, 쓰거나 실행하지는 않습니다. `--yes`는 먼저 묻지 않고 도구를 실행합니다. 묻지 않아도 안전한 곳에서만 쓰세요.

## 슬래시 명령

대화에서 `/`를 입력하면 다음 명령이 보입니다:

| 명령 | 하는 일 |
|---|---|
| `/help` | 여기서 Letronna가 할 수 있는 일 |
| `/new` | 새 세션 시작 |
| `/plan` | 읽기와 검색만, 쓰기나 실행은 없음 |
| `/model` | 모델 표시 또는 변경. 이미지·음성·동영상 모델은 뒤에 image, speech, video를 붙여 지정 |
| `/gateways` | 게이트웨이 보기, 추가, 제거 |
| `/team` | 호스팅 모델 비용을 팀 풀에서 차감할지 내 크레딧에서 차감할지 선택 |
| `/login` | Letronna에 로그인 |
| `/logout` | 이 컴퓨터에서 로그아웃 |
| `/whoami` | 누가 로그인했는지 확인 |
| `/effort` | 모델이 얼마나 깊이 생각할지 |
| `/thinking` | 모델의 사고 과정 표시 또는 숨김 |
| `/search` | 모델이 웹을 검색하게 허용 |
| `/jobs` | 백그라운드에서 아직 실행 중인 명령 |
| `/skills` | 모델에 건넬 수 있는 저장된 지침 |
| `/resume` | 이전 세션 이어 가기 |
| `/where` | 프로젝트 폴더와 세션 파일 표시 |
| `/clear` | 화면 지우기 |
| `/exit` | 나가기 |
