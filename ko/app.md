창은 에이전트가 들어 있는 채팅입니다. 왼쪽에 세션 목록이 검색, 고정, 날짜별 그룹과 함께 있습니다. 세션마다 디스크에 별도 파일이라 Letronna 두 개를 동시에 실행할 수 있습니다.

## 대화하기

- 답변은 마크다운으로 스트리밍됩니다. 에이전트가 쓰는 도구(파일 읽기, 명령 실행, 웹 페이지 읽기, 지난 세션 검색)는 채팅에 표시되고, 컴퓨터를 바꾸는 일은 무엇이든 먼저 묻습니다.
- 모델은 모델 메뉴에서 고르세요. Letronna와 설정한 각 게이트웨이의 모든 모델이 나열되고, 메시지는 고른 모델의 게이트웨이로 갑니다.
- Effort(얼마나 깊이 생각할지), thinking(사고 과정 표시), 웹 검색은 모델이 지원하면 켜고 끌 수 있습니다.
- 대화가 모델의 컨텍스트 창보다 커지면, 오래된 턴은 잊히는 대신 요약됩니다.

## 설정

- **Gateways**: 게이트웨이마다 상태(로그인됨, 연결됨, 설정 안 됨, 실행 안 됨)와 키.
- **Account**: 누가 로그인했는지, 내 크레딧, 그리고 호스팅 모델 비용을 누가 내는지(나 자신 또는 내가 속한 팀).

창에는 Telegram과 Discord로도 접근할 수 있고, 예약 작업은 그곳으로 결과를 보고합니다. Artifacts와 Skills는 별도 페이지가 있습니다.

## 시스템별 차이

|  | Windows | Linux | macOS |
|---|---|---|---|
| 채팅과 에이전트 도구 | 예 | 예 | 예 |
| 자체 설치 및 제거 | 예 | 예 | 응용 프로그램 폴더로 드래그 |
| 한 번에 창 하나 | 예, 열린 창에 포커스 | 예 | 아니요 |
| 트레이 아이콘 | 예 | 예(KDE, GNOME은 AppIndicator 필요) | 아니요 |
| 대화 상자 뒤 흐림 효과 | 예 | 아니요 | 아니요 |

Windows와 Linux에서는 창을 닫아도 Letronna가 트레이에 남습니다. 아이콘을 클릭하면 다시 나타나고, 우클릭하면 종료할 수 있습니다. 제거는 Windows의 “앱 및 기능”에서 하거나 `letronna --uninstall`로 합니다.
