Тот же агент, но в терминале: с тем же аккаунтом, сессиями и настройками, что и в приложении.

## Запуск

| Команда | Что делает |
|---|---|
| `letronna` | открывает разговор |
| `letronna -p "question"` | задаёт один вопрос, выводит ответ и завершается |
| `letronna --continue` | продолжает последнюю сессию |
| `letronna --resume` | предлагает выбрать одну из недавних сессий; с идентификатором открывает именно её |
| `letronna gui` | открывает окно вместо терминала |
| `letronna setup` | имя, вход, провайдер, модель, установка |
| `letronna --uninstall` | удаляет Letronna с компьютера |

`--plan` запускает агента в режиме планирования: только чтение и поиск, без записи и запуска команд. `--yes` запускает инструменты, не спрашивая разрешения, — используйте этот флаг только там, где это безопасно.

## Слеш-команды

Введите `/` в разговоре, чтобы увидеть их список:

| Команда | Что делает |
|---|---|
| `/help` | показывает, что Letronna умеет здесь |
| `/new` | начинает новую сессию |
| `/plan` | только чтение и поиск, без записи и запуска команд |
| `/model` | показывает или меняет модель; с image, speech или video — модель для изображений, речи или видео |
| `/gateways` | показывает, добавляет или удаляет шлюзы |
| `/team` | выбирает, кто платит за размещённые модели: команда или вы сами |
| `/login` | выполняет вход в Letronna |
| `/logout` | выполняет выход из аккаунта на этом компьютере |
| `/whoami` | показывает, кто вошёл в аккаунт |
| `/effort` | задаёт, насколько усердно должна думать модель |
| `/thinking` | показывает или скрывает рассуждения модели |
| `/search` | разрешает модели искать в интернете |
| `/jobs` | показывает команды, которые ещё выполняются в фоне |
| `/skills` | показывает сохранённые инструкции, которые можно передать модели |
| `/resume` | продолжает одну из прошлых сессий |
| `/where` | показывает папку проекта и файл сессии |
| `/clear` | очищает экран |
| `/exit` | завершает работу |
