Letronna хранит свои данные в одной папке на вашем компьютере:

- Windows: `%LOCALAPPDATA%\Letronna\`
- macOS: `~/Library/Application Support/Letronna/`
- Linux: `~/.local/share/Letronna/`

| Файл | Что хранит |
|---|---|
| `chats.json` и сессии | ваши разговоры, а также выбранные шлюз и модель |
| `keys.json` | API-ключи для каждого шлюза, обычным текстом и только на вашем диске |
| `account.json` | данные входа в Letronna на этом компьютере |
| `SOUL.md` | кем является Letronna, вашими словами (необязательно) |
| `USER.md`, `MEMORY.md` | что агент знает о вас и его собственные заметки; их можно править в любой момент |
| `mcp.json` | MCP-серверы, инструментами которых агент может пользоваться (необязательно) |
| `media/` | изображения, речь и видео, созданные без подключённого проекта |

Если подключена папка проекта, её `AGENTS.md` читается как инструкции проекта. Текст чата уходит только в выбранный вами шлюз и больше никуда; для шлюза Letronna это api.letronna.ai, который записывает модель и стоимость каждого запроса для вашей страницы «Расход». Задача, которую вы отправляете в [Letronna Cloud](/docs/cloud), выполняется на серверах Letronna и получает только то, что несёт с собой сама задача.

## Инструменты MCP-серверов

Перечислите в `mcp.json` MCP-серверы, которые запускаются локальной командой, в том же формате, что используют Claude Desktop и Cursor:

```sh
{
  "mcpServers": {
    "everything": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-everything"],
      "autoApprove": ["echo"]
    }
  }
}
```

Инструменты серверов появляются, как только серверы ответят. Перед каждым вызовом агент спрашивает разрешения, если инструмента нет в `autoApprove`; `"disabled": true` оставляет сервер выключенным.
