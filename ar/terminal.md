الوكيل نفسه في الطرفية، بالحساب والجلسات والإعدادات نفسها التي في التطبيق.

## بدء التشغيل

| الأمر | الوظيفة |
|---|---|
| `letronna` | فتح محادثة |
| `letronna -p "question"` | سؤال مرة واحدة، وطباعة الجواب، ثم الخروج |
| `letronna --continue` | متابعة أحدث جلسة |
| `letronna --resume` | الاختيار من الجلسات الأخيرة؛ ومع معرّف، فتح تلك الجلسة |
| `letronna gui` | فتح النافذة بدلاً من ذلك |
| `letronna setup` | الاسم، وتسجيل الدخول، والبوابة، والنموذج، والتثبيت |
| `letronna --uninstall` | الإزالة |

`--plan` يبدأ في وضع التخطيط: قراءة وبحث فقط، دون كتابة أو تشغيل أبداً. `--yes` يشغّل الأدوات دون أن يسأل أولاً — استخدمه فقط حيث يكون ذلك آمناً.

## أوامر الشرطة المائلة (slash)

اكتب `/` في محادثة لترى هذه الأوامر:

| الأمر | الوظيفة |
|---|---|
| `/help` | ما الذي يستطيع Letronna فعله هنا |
| `/new` | بدء جلسة جديدة |
| `/plan` | قراءة وبحث فقط، دون كتابة أو تشغيل أبداً |
| `/model` | عرض النموذج أو تغييره؛ أضف image أو speech أو video لتغيير نموذج ذلك النوع |
| `/gateways` | عرض البوابات أو إضافتها أو إزالتها |
| `/team` | احتساب النماذج التي تستضيفها Letronna على فريق، أو على نفسك |
| `/login` | تسجيل الدخول إلى Letronna |
| `/logout` | تسجيل الخروج على هذا الجهاز |
| `/whoami` | من سجّل الدخول |
| `/effort` | مقدار الجهد الذي يبذله النموذج في التفكير |
| `/thinking` | عرض تفكير النموذج أو إخفاؤه |
| `/search` | السماح للنموذج بالبحث في الويب |
| `/jobs` | الأوامر التي ما زالت تعمل في الخلفية |
| `/skills` | تعليمات محفوظة يمكنك تمريرها إلى النموذج |
| `/resume` | متابعة جلسة من قبل |
| `/where` | عرض مجلد المشروع وملف الجلسة |
| `/clear` | مسح الشاشة |
| `/exit` | الخروج |
