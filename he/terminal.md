אותו סוכן, בטרמינל, עם אותו חשבון, אותם סשנים והגדרות כמו באפליקציה.

## הפעלה

| פקודה | פעולה |
|---|---|
| `letronna` | פתיחת שיחה |
| `letronna -p "question"` | שאלה אחת, הדפסת התשובה ויציאה |
| `letronna --continue` | המשך הסשן האחרון |
| `letronna --resume` | בחירה מהסשנים האחרונים; עם מזהה, פתיחה של אותו סשן |
| `letronna gui` | פתיחת החלון במקום הטרמינל |
| `letronna setup` | שם, התחברות, שער, מודל, התקנה |
| `letronna --uninstall` | הסרה |

`--plan` מתחיל במצב תכנון: קריאה וחיפוש בלבד, לעולם לא כתיבה או הרצה. `--yes` מריץ כלים בלי לשאול קודם; השתמשו בו רק במקום שבו זה בטוח.

## פקודות לוכסן

הקלידו `/` בשיחה כדי לראות אותן:

| פקודה | פעולה |
|---|---|
| `/help` | מה Letronna יכול לעשות כאן |
| `/new` | התחלת סשן חדש |
| `/plan` | קריאה וחיפוש בלבד, לעולם לא כתיבה או הרצה |
| `/model` | הצגה או שינוי של המודל; הוסיפו image, speech או video כדי לבחור מודל לאלה |
| `/gateways` | הצגה, הוספה או הסרה של שערים |
| `/team` | חיוב המודלים שמאוחסנים אצלנו לצוות או לעצמכם |
| `/login` | התחברות ל-Letronna |
| `/logout` | יציאה מהחשבון במחשב הזה |
| `/whoami` | מי מחובר |
| `/effort` | כמה קשה המודל צריך לחשוב |
| `/thinking` | הצגת החשיבה של המודל, או הסתרתה |
| `/search` | מאפשר למודל לחפש ברשת |
| `/jobs` | פקודות שעדיין רצות ברקע |
| `/skills` | הוראות שמורות שאפשר להעביר למודל |
| `/resume` | המשך סשן מהעבר |
| `/where` | הצגת תיקיית הפרויקט וקובץ הסשן |
| `/clear` | ניקוי המסך |
| `/exit` | יציאה |
